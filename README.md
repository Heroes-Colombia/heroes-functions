# Heroes, Functions
This project is a Firestore Cloud functions project that is used to manage the heroes web admin panel.

## Installation steps
1. Clone the repository
```bash
git clone
```
2. Change the directory to the project directory
```bash
cd functions
```
3. Install the dependencies
```bash
npm install
```
4. Run the project
```bash
npm run serve
```

- Dont forget to set the environment variables in the `.env` file
- Dont forget to sign in to firebase using `firebase login` command and make sure that you have the correct permissions to deploy and run the functions
